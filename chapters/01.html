Chapter 1

Ideas, Materials, Technologies and Aesthetics

From Canova's marble to Fontana's spatial cuts: a journey through neoclassicism, spatialism, and the emergence of digital-physical art practice.

Scripts

Run directly in Blender 5.x (Scripting workspace) or via the Windows .bat launchers.

🪟 Windows — .bat launchers Each script comes with a .bat file you can double-click directly from File Explorer. It automatically finds Blender (trying 5.1, 5.0, 4.x in order) and runs the script — no terminal needed. Example: double-click run_fontana_cut.bat and Blender opens with the scene already generated.

🍎 macOS / 🐧 Linux — .sh launchers Use the .sh files included in the same folder. The first time you use a script, the system needs to allow it to run: right-click the .sh file → Open With → Terminal, and confirm. After that, you can open it directly by double-clicking.
