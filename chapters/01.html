Blender 5.x

fontana_cut.py

↗ View on GitHub

A procedural reinterpretation of Lucio Fontana's Concetto Spaziale. The script builds a vertical linen canvas (a thin manifold cube) and carves into it a series of organic cuts using Blender's boolean DIFFERENCE modifier. Each blade is a custom bmesh volume: its spine follows a gentle sine curve, the width tapers to zero at both tips, and each edge carries independent noise — reproducing the slabbrato, the frayed, torn quality of a real Fontana cut.

Parameter Default Description
NUM_CUTS 5 Number of cuts — Fontana typically used 1–7
CUT_ANGLE 10.0° Slight lean from vertical — alternates ±
CUT_DEPTH 0.08 Depth the blade protrudes through the canvas
CUT_WIDTH 0.015 Blade thickness — thin = sharp cut, wider = torn gap
CUT_LENGTH 0.72 Cut length as fraction of canvas height
CANVAS_SIZE 2.0 Canvas half-extent in Blender units
SPACING "even" "even" · "random" · "golden"
SEED 42 Random seed for reproducible organic variations
Blender 5.x

parametric_space.py

↗ View on GitHub

Translates the chapter's central idea — space as a generative field — into geometry. A dense grid of vertices is deformed by a mathematical field equation, producing a membrane that ripples, bends, and expands as if responding to an energy source. Three field profiles: radial (concentric rings, Fontana-like), linear (directional wave), turbulent (procedural noise, organic surface). Optional Solidify makes the result print-ready.

Parameter Default Description
GRID_DENSITY 40 Vertices per side — 40 = 1 600 points
GRID_SIZE 4.0 Total extent in Blender units
WAVE_AMPLITUDE 0.35 Height of field deformation — energy intensity
WAVE_FREQUENCY 2.5 Oscillation cycles — compression of spatial rhythm
FIELD_PROFILE "radial" "radial" · "linear" · "turbulent"
NOISE_SCALE 1.8 Turbulence detail scale — turbulent mode only
SOLIDIFY True Add thickness — makes the surface print-ready
EMIT_PARTICLES False Particle system — visualise energy propagation
Workflow note: designed to run in the same Blender session as fontana_cut.py. It removes only the default startup objects (Cube, Camera, Light) and leaves the FontanaCanvas untouched — both scripts can coexist in one scene.
Blender 5.x

reproduction_matrix.py

↗ View on GitHub

A three-dimensional visualisation of Walter Benjamin's thesis: a row of objects representing successive generations of reproduction. The original (left) is pristine — warm amber, full aura. Moving right, Musgrave noise erodes the form progressively. Material colour shifts from warm ochre to cold blue-grey — temperature mapping the presence or absence of aura.

Parameter Default Description
NUM_COPIES 7 Total objects — original + N−1 reproductions
BASE_FORM "sphere" "sphere" · "cube" · "torus"
MAX_NOISE 0.55 Displacement strength at the last generation
SPACING 1.6 Distance between objects in Blender units
SEED 17 Random seed — change to explore degradation variants
