Scripts

Run directly in Blender 5.x (Scripting workspace) or via the Windows .bat launchers.

⚠️ Do not double-click the .py files directly These are Blender scripts — use the .bat launcher (Windows) or .sh launcher (macOS/Linux) in the same folder. Full instructions: Getting Started →
Blender 5.x

fontana_cut.py

Parametric reinterpretation of Fontana's Concetto Spaziale: organic boolean cuts — curved, tapered, frayed — carved into a linen canvas. Parameters: number of cuts, angle, spacing mode (even · random · golden).

↗ View on GitHub
Blender 5.x

parametric_space.py

Space as a generative field: a vertex grid deformed by a mathematical equation. Three profiles — radial (concentric, Fontana-like), linear (directional wave), turbulent (procedural noise). Runs in the same session as fontana_cut.py.

↗ View on GitHub
Blender 5.x

material_spectrum.py

The same sculptural form rendered in five material states: white marble → terracotta → bronze → digital glass → wireframe. A row that maps the arc from Canova's studio to the 3D printer — the central argument of the chapter.

↗ View on GitHub
