Scripts

Standard Python 3.x — no Blender required for most scripts. Double-click the .bat launcher (Windows) or run from the terminal.

Three levels of digital certification Level 1 — blender_metadata.py: Custom Properties inside the .blend (informal) · Level 2 — certify_asset.py: SHA-256 fingerprint + .cdm.json (verifiable) · Level 3 — OpenTimestamps: blockchain timestamp (permanent).
Python 3.x · §4.1

aura_transition.py

Plots Aura and Reproducibility as two crossing curves across five historical phases. Output: ref_aura_transition_diagram.svg.

↗ View on GitHub
Python 3.x · §4.3.4 · App. A

certify_asset.py

SHA-256 fingerprint + .cdm.json for any file. Drag any file onto run_certify_asset.bat or use --verify to check integrity.

↗ View on GitHub
Blender 5.x · §4.2.2

blender_metadata.py

Writes author, title, date, license, version to Scene Custom Properties. Edit CONFIG block → Alt+P to apply.

↗ View on GitHub

3D Models

A live demonstration of the three certification levels described in §4.2.2.

File Level Description
metadata_demo.blend Level 1 Open in Blender → Scene Properties → Custom Properties: metadata already set.
metadata_demo.blend.cdm.json Level 2 SHA-256 certificate of the .blend. Verify with: python certify_asset.py metadata_demo.blend --verify
