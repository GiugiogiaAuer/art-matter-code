Scripts

Run directly in Blender 5.x (Scripting workspace) or via the Windows .bat launchers.

⚠️ Do not double-click the .py files directly These are Blender scripts — use the .bat launcher (Windows) in the same folder. Full instructions: Getting Started →
Blender 5.x · §3.6.1.1

organic_surface.py

Transforms a flat plane into organic relief using procedural displacement. Texture type, strength, and subdivisions are all configurable.

↗ View on GitHub
Blender 5.x · §3.6.1.3

lattice_structures.py

Wireframe modifier and Voxel Remesh compared side by side. Controls: strut thickness, voxel size, decimation ratio.

↗ View on GitHub
Blender 5.x · §3.6.1.5

fluid_geometry.py

120-frame fluid deformation animation. Press Space to play. Exportable as GLB for metaverse platforms.

↗ View on GitHub
Blender 5.x · §3.3

fibonacci_growth.py

Golden-angle phyllotaxis spiral in 3D. Configurable elements, height, noise jitter, and module type (sphere / cube / cone).

↗ View on GitHub
Blender 5.x · §3.6.2

picasso_gesture.py

Bézier gesture → glowing volumetric trace, 80-frame self-drawing animation. Dark world environment.

↗ View on GitHub
