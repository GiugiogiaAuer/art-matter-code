Getting Started

How to download the materials and run the scripts — no programming experience required.

1 — Download the materials

All files are freely available on GitHub. You can download everything at once or just the chapter you need.

  1. Go to the repository: github.com/Apress/Art-Between-Matter-and-Code
  2. Click the green Code button → Download ZIP. This downloads all chapters at once.
  3. Unzip the file. Each chapter has its own folder (01/, 02/, …) with subfolders for images, scripts, models, and documents.

2 — Install Blender

All 3D scripts require Blender 5.x. Download it for free from the official site.

Download Blender

Already have Blender?  Version 4.2 or later also works. The launchers automatically detect whichever version you have installed.

3 — Run a script

Each chapter's scripts/ folder contains Python files (.py) and launchers. Do not double-click the .py files directly — they are Blender scripts and will not work with regular Python. Use the launchers instead.

🪟 Windows

Double-click the .bat file in the same folder as the script. A black window opens briefly, then Blender launches with the scene already generated.

Example: to run fontana_cut.py, double-click run_fontana_cut.bat.

🍎 macOS  /  🐧 Linux

Double-click the .sh file. The first time only, the system may ask for permission: right-click → Open With → Terminal, and confirm.

Example: to run fontana_cut.py, double-click run_fontana_cut.sh.

4 — Open a script inside Blender

You can also run and edit scripts directly from inside Blender, without the launchers.

  1. Open Blender.
  2. Click the Scripting tab at the top of the screen.
  3. Click Open and select the .py file from the chapter's scripts/ folder.
  4. Press Alt + P (or click the ▶ Run Script button) to execute it.
Tip:  Each script has a CONFIG block at the top where you can change parameters (number of cuts, grid density, amplitude…) before running.

5 — Open a .blend scene

Each chapter's models/ folder contains ready-made Blender scenes (.blend files). Open them directly in Blender: File → Open → select the .blend file.
